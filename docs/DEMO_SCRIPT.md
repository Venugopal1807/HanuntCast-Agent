# Blackthorn House — 2–3 minute demo

## Recording gate

The current task authorizes no paid synthesis. Do not follow a live Play instruction below until the operator explicitly approves a bounded paid narration session. Use the restricted HTTPS/local demo behind a private proxy with the existing durable ledger, never the anonymous public mock site for live recording. Confirm its LIVE TTS badge. Keep credentials, env files, proxy configuration, request headers, terminals and private host details out of the recording. Check microphone/system-audio capture locally before recording; the product itself does not capture microphone input.

If no further paid calls are authorized, use an existing authorized narration recording if available and clearly identify it as a prior sample, or record the mock flow and label it MOCK AUDIO. Do not call the mock soundscape actual AssemblyAI narration. Historical short audio proves only that short sample; it does not narrate all scene text. A finished live demo recording is still an operator task.
